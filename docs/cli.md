# CLI

`shopify-scope-guard audit [path]` supports `--format human|json|sarif`, `--config`, `--fail-on none|low|medium|high`, `--path`, and `--include`.

`shopify-scope-guard rules` prints the bundled evidence registry. `shopify-scope-guard explain SG-SCOPE-001` prints matching evidence entries. `shopify-scope-guard version` prints the package version.
