# Rule reference

`SG-SCOPE-001` reports a high-confidence required scope that is not declared or satisfied by a documented implied scope.

`SG-SCOPE-002` reports a high-confidence operation whose needed scope is declared only as optional.

`SG-SCOPE-003` reports a documented redundant read scope, such as `write_products` plus `read_products`.

`SG-SCOPE-004` reports that no supported usage requiring a declared scope was evidenced. It does not claim the scope is unused.

`SG-SCOPE-006` reports unmapped Shopify-related code as UNKNOWN.
