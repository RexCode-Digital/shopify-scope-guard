# Roadmap

Priorities are evidence-led and may change as Shopify APIs evolve:

- Expand verified Shopify scope coverage, including additional classic webhook topic mappings when official evidence and regression fixtures are available.
- Add additional Admin API surfaces without mixing evidence confidence levels.
- Improve alternative-scope modeling and API-version-aware evidence.
- Reduce false positives and improve UNKNOWN handling.
- Expand privacy-safe consumer and action fixture coverage.
